# 🤖 CodeAlpha ChatBot

## 📌 Description
A simple Python chatbot developed as part of the CodeAlpha Python Programming Internship.

## ✨ Features
- Greets the user
- Tells the current date and time
- Tells random jokes
- Shows motivational quotes
- Performs basic calculations
- Help menu
- Personalized conversation using the user's name

## 🛠 Technologies Used
- Python 3
- datetime module
- random module

## ▶️ How to Run

1. Clone the repository.
2. Open the project folder.
3. Run:

```bash
python chatbot.py
```

## 📷 Sample Commands

- hello
- help
- date
- time
- joke
- quote
- calculator
- bye
